No usage API exists — these tiles cannot be populated

Usage is recorded server-side, but the deployed API exposes no endpoint that reads it back: there is no per-caller totals endpoint, no usage-history endpoint and no cost aggregation. The panel below is the interface shell only. It shows no numbers because there are no real numbers to show, and it will not invent any.

What already exists server-side

Every request is metered with the fields below. Building the panel above is a matter of exposing a read endpoint over this table — the measurement layer is already in place and is billing-ready in the sense that input and output tokens are stored separately per call.

Only same-day totals per caller are aggregated today, and only for the allowance check. Per-key attribution, multi-day history and cost rollups all require the API-key work described next.
